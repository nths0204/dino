# 小恐龍跑酷遊戲

這是一個類似 Chrome 小恐龍遊戲的 2D 橫向跑酷網頁，使用純 HTML、CSS 和 JavaScript 製作。

## 遊玩方式

1. 開啟 `index.html` 直接遊玩，或在專案目錄執行本地伺服器。
2. 按下 `Space`、`↑` 或滑鼠點擊畫面即可跳躍。
3. 避開仙人掌與飛鳥，盡量跑得更遠。

## 啟動本地伺服器

在專案目錄中執行：

```bash
python -m http.server 8000
```

然後在瀏覽器打開：

```text
http://localhost:8000
```
